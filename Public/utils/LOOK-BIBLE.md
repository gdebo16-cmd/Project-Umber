# Eldridia — Default Class Model Look Bible (v1 draft)

**Purpose:** Stable defaults for player handouts / VTT. Human Lys-midland heroes unless noted. Full-body 3/4, readable silhouette, soft painterly fantasy, neutral backdrop. Palette cues below lock redraws.

**Art direction:** Clean TTRPG concept art; no busy backgrounds; gear readable at token scale; consistent lighting (soft key from upper left).

**Shared locks**
- Setting cue: Lys grassy midlands fantasy (Umbermere), not generic “generic DnD tavern.”
- No Forge Master / Hollowmancer iconography on defaults.
- Witch Green Magic ≠ Druid: witch uses charms/hex marks; druid uses living plant/hide.
- Paladin default oath: **Oath of Ochre** (life / bright green-gold).

**Output files:** `class-XX-name.png` full-body 3:4 plus optional later token crop.
